# IZRADA PORTFOLIO CASE STUDY-JA

Glavni cilj:

> Sprovedite praktičan, evidence-based workflow za "Izrada portfolio case study-ja", sa verifikovanim iskustvom, jasnim signalima i bez izmišljanja podataka.

## 1. KONTEKST

Define target role/company, actual experience, achievements, constraints, seniority, location/remote preference, application stage and desired outcome.

## 2. DOMAIN STANDARD

Optimize for human readability first and ATS parseability second. Mirror genuine terminology from the target role only where it truthfully matches experience. Portfolio cases should show context, decision, action, evidence and outcome.

## 3. INTEGRITY CHECKS

- every bullet maps to real work
- metrics are sourced or omitted
- keywords reflect actual capability
- format remains machine-readable
- portfolio artifacts protect confidential information
- career story is consistent across CV, LinkedIn and portfolio

## 4. EVIDENCE CARD

```text
Claim:
Source experience:
Action:
Scope:
Result:
Metric:
Context:
Relevance:
Confidence:
```

## 5. OBAVEZNE MATRICE

### Evidence-to-Bullet Matrix
| Experience | Action | Result | Metric | Target requirement | Draft |
|---|---|---|---|---|---|

### ATS Fit Matrix
| Requirement/keyword | Evidence | Present? | Natural wording | Gap |
|---|---|---|---|---|

## 6. FAILURE MODES

Avoid fabricated metrics, generic adjectives, keyword stuffing, vague outreach, rehearsed answers with no evidence, irrelevant portfolio material and activity metrics that do not improve conversion.

## 7. OBAVEZNI OUTPUT

1. Target and context.
2. Evidence inventory.
3. Fit/gap analysis.
4. Draft or workflow.
5. Quality risks.
6. Required matrices.
7. Next action.
8. Verification checklist.

End with **Provera integriteta prijave** confirming that every material claim is supported by real experience or explicitly marked as an assumption.

Ovaj prompt podržava karijerni rad i ne garantuje selekciju ili ponudu.
