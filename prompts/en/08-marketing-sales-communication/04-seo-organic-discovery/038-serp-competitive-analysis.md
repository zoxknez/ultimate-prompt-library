# SERP COMPETITIVE ANALYSIS

Main objective:

> Perform SERP Competitive Analysis through search intent, technical accessibility, useful content, internal architecture and measurable organic outcomes.

## 1. SEARCH CONTEXT
Define query/topic, market/language, intent, current SERP pattern, existing asset, business relevance, conversion path and measurement window.

## 2. SEO STANDARD
- solve user intent first
- infer query intent from current evidence where possible
- avoid keyword stuffing
- separate crawl/index/render issues from content issues
- prioritize technical fixes by likely impact
- avoid cannibalization
- use internal links where genuinely useful
- treat rankings as outcomes, not promises

## 3. SEO CARD
```text
Query/topic:

Current asset:
```

## 5. FAILURE MODES
Avoid thin pages, duplicated intent, generic AI-expanded copy, fake expertise, technical busywork with no impact and conclusions from short-term ranking noise.

## 6. REQUIRED OUTPUT
1. Search intent.
2. SERP/content gap.
3. Technical/content priorities.
4. Internal architecture.
5. Required matrices.
6. Conversion path.
7. Measurement plan.
8. Refresh trigger.

End with **SEO Integrity Check** confirming content is useful to users and no ranking guarantee is implied.

This supports SEO planning and does not guarantee search rankings.
