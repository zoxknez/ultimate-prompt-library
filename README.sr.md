<a id="o-projektu"></a>

## Za zadatke kojima treba više od brzog odgovora

UPL je model-agnostic biblioteka detaljnih uputstava za rad uz AI. Promptovi definišu zadatak, granice, dokaze koje treba proveriti, moguće načine greške, očekivani format i provere koje olakšavaju procenu rezultata.

<a id="razlike"></a>

### Dosledan standard, prilagođen zadatku

- **Jasne smernice:** Svaki prompt definiše ulogu, cilj, obim i zadatke koji nisu predmet rada.
- **Dokazi pre tvrdnji:** Prioriteti izvora, nivoi pouzdanosti i zaštita od lažno pozitivnih nalaza smanjuju neproverene zaključke.
- **Koristan rezultat:** Konkretan format izlaza, primeri i očekivana pokrivenost pretvaraju analizu u rezultat koji može da se pregleda.
- **Ugrađena provera:** Praktične provere i završna kontrola kvaliteta uključeni su kada ih zadatak zahteva.

Kompletna specifikacija nalazi se u [vodiču za format promptova](docs/prompt-format.sr.md).

**Izdvojeni prompt:** [UPL-IT-001 · Forensic Full Repository Audit](prompts/sr/01-it-programiranje-tehnologija/01-web-development/001-forensic-full-repository-audit.md) · [English](prompts/en/01-it-programming-technology/01-web-development/001-forensic-full-repository-audit.md)

<a id="kako-se-koristi"></a>

## Kako da koristiš prompt

1. **Izaberi zadatak.** Otvori odgovarajući prompt na srpskom ili engleskom. Indeksi organizuju sadržaj po oblastima i podkategorijama.
2. **Dodaj uputstva.** Kopiraj sadržaj u ChatGPT, Claude, Gemini, coding agent ili drugi sposoban model. Front matter su metapodaci i možeš da ga izostaviš.
3. **Dodaj kontekst.** Priloži repozitorijum, fajlove, dokumente ili podatke potrebne za zadatak. Model može da proceni samo materijal i alate koje ima na raspolaganju.
4. **Proveri rezultat.** Suzi obim kada je korisno, pa proveri nalaze u izvornom materijalu pre nego što se osloniš na rezultat.

Mašinski čitljiv [`prompts.json`](indexes/prompts.json) navodi ID, naziv, status, verziju i putanju svakog prompta.

<a id="struktura"></a>

## Kako je repozitorijum organizovan

- [`prompts/sr/`](prompts/sr/) i [`prompts/en/`](prompts/en/): usklađeni promptovi na srpskom i engleskom, grupisani po oblastima i podkategorijama.
- [`catalog.json`](catalog.json): definicije oblasti, trajni ID prefiksi i planirani promptovi.
- [`indexes/`](indexes/): generisani indeksi, statistika kolekcije i mašinski čitljivi podaci.
- [`docs/`](docs/): format prompta, pravila za ID-eve, prevod, arhitektura i roadmap.
- [`scripts/`](scripts/) i [`site-src/`](site-src/): alati za validaciju, generisanje i izvorni kod pretraživog sajta.

<a id="jezici"></a>

## Dva jezika, jedan trajni identitet

**Srpski, latinica:** Kompletno izdanje promptova nalazi se u [`prompts/sr/`](prompts/sr/).

**English:** Primarni jezik za pisanje promptova nalazi se u [`prompts/en/`](prompts/en/).

Obe verzije imaju isti ID, broj, slug i verziju. Prompt dobija status `stable` kada postoje sve podržane jezičke verzije. Tehnički termini ostaju na engleskom kada je tako prirodnije. Pogledaj [vodič za prevođenje](docs/translation-guide.md).

<a id="format"></a>

## Promptovi su verzionisani dokumenti

Svaki Markdown prompt počinje YAML metapodacima. Trajni ID povezuje jezičke verzije, a verzija beleži značajne izmene uputstava.

**Identitet i putanja:** `id`, `number`, `slug`, oblast i podkategorija čine fajlove prepoznatljivim i organizovanim.

**Jezik i status:** `language`, `version` i `status` govore koje izdanje čitaš i da li je spremno za upotrebu.

Pravila polja, verzionisanje i preporučena struktura opisani su u [docs/prompt-format.sr.md](docs/prompt-format.sr.md). Pre dodeljivanja ili izmene ID-a pogledaj [docs/ids.md](docs/ids.md).

<a id="doprinos"></a>

## Pomozi da biblioteka raste

- **Unapredi ili prevedi:** Zadrži trajni ID i ime fajla. Ažuriraj oba jezička izdanja i povećaj verziju kada se uputstva promene.
- **Napiši planirani prompt:** Koristi ID koji je već rezervisan u `catalog.json`. Ne dodeljuj zamenski ID za planirani unos.
- **Predloži novi prompt:** Počni od procesa za predlaganje. ID se dodaje u katalog tek kada predlog bude prihvaćen.
- **Pokreni provere projekta:** Instaliraj alate, regeneriši izvedene fajlove i proveri strukturu i linkove pre pull request-a.

```bash
npm ci
npm run generate
npm run validate
```

Pogledaj [uputstvo za doprinos](CONTRIBUTING.sr.md), [Kodeks ponašanja](CODE_OF_CONDUCT.md) i [bezbednosnu politiku](SECURITY.md).

<a id="kvalitet"></a>

## Kvalitet i bezbedna upotreba

**Šta validacija proverava:** Metapodatke, ID-eve, imena fajlova, jezičke parove, generisane indekse i interne linkove. Proverava strukturu repozitorijuma, a ne kvalitet AI odgovora.

**Bezbednosni rad mora biti ovlašćen:** Bezbednosne promptove koristi za defanzivni pregled, bezbedan razvoj i sisteme koje poseduješ ili imaš izričito ovlašćenje da testiraš. Pogledaj [SECURITY.md](SECURITY.md).

Uvek proveri AI odgovor prema izvornom materijalu i zahtevima zadatka.

<a id="roadmap"></a>

## Napredak i sledeći koraci

**Završeno:** IT, programiranje i tehnologija i Ekonomija, finansije i poslovanje imaju po 100 objavljenih promptova.

**Planirano:** Preostalo je osam trajnih oblasti. Razvijaće se jedna po jedna, bez menjanja postojećih ID-eva.

**Aktivan web sajt:** Pretraga, filteri oblasti i podkategorija, izbor jezika, kopiranje i trajni linkovi promptova.

**Roadmap:** Planove kolekcija i smer razvoja pogledaj u [kompletnom roadmap-u](docs/roadmap.sr.md).
