# AUDIT MENJANJA KONTEKSTA

Glavni cilj:

> Izgradite ili auditujte "Audit menjanja konteksta" kao izvršiv sistem prioriteta, kapaciteta i review ritma, bez pretvaranja produktivnosti u beskrajno praćenje zadataka.

## 1. OPERATIVNI KONTEKST
Capture commitments, roles, deadlines, calendar constraints, energy/focus constraints, recurring work, current tools, WIP and major dependencies.

## 2. SPECIJALIZOVANI TOK
- identify repeated switches
- classify source
- estimate recovery cost qualitatively/quantitatively
- batch compatible work
- redesign notification/meeting triggers
- measure improvement

## 3. PRIORITY DISCIPLINA
A priority system must define what is not being done. Distinguish:
- outcome
- project
- task
- recurring responsibility
- waiting/delegated work
- reference
- someday/maybe

## 4. EXECUTION CARD
```text
Outcome:
Why now:
Owner:
Next action:
Deadline/trigger:
Dependency:
Effort/capacity:
WIP stage:
Blocker:
Review date:
Done definition:
```

## 5. OBAVEZNE MATRICE
### Priority Matrix
| Work | Outcome value | Urgency | Dependency | Effort | WIP | Decision |
|---|---|---|---|---|---|---|

### Capacity Matrix
| Time block | Planned work | Required focus | Buffer | Conflict | Action |
|---|---|---|---|---|---|

### Review Matrix
| Commitment | Status | Blocker | Next action | Drop/defer/delegate/do | Review |
|---|---|---|---|---|---|

## 6. FAILURE MODES
Avoid infinite task lists, priority inflation, calendar overbooking, hidden WIP, excessive app/tool complexity, planning without review and tracking metrics that reward busyness rather than completed outcomes.

## 7. OBAVEZNI OUTPUT
1. Current commitments.
2. Priority logic.
3. WIP/capacity limits.
4. Execution plan.
5. Required matrices.
6. Review cadence.
7. Stop/defer/delegate decisions.
8. System simplification.

End with **Provera integriteta produktivnosti** confirming that priorities fit real capacity and every active commitment has a next action or explicit disposition.
