# IZRADA VALUE PROPOSITION-A

Glavni cilj:

> Izgradite ili auditujte "Izrada value proposition-a" tako da poruka bude jasna, relevantna, dokaziva i usklađena sa nivoom svesti publike.

## 1. KONTEKST

Define audience, problem, alternative, offer, awareness stage, channel, proof, objections, CTA and brand constraints.

## 2. MESSAGE STANDARD

Build messaging from audience problem, alternative, value and proof. Copy should reduce ambiguity and make the next action clear. Do not use false urgency, fabricated proof or unsupported superlatives.

## 3. INTEGRITY CHECKS

- value proposition is specific to audience/problem
- claims have proof
- benefits are translated from features
- message hierarchy matches awareness stage
- CTA is explicit
- brand voice does not reduce clarity
- social proof is genuine
- urgency/scarcity is factual

## 4. MESSAGE CARD

```text
Audience:
Problem:
Alternative:
Value:
Differentiator:
Proof:
Objection:
CTA:
Risk:
```

## 5. OBAVEZNE MATRICE

### Message Hierarchy
| Layer | Message | Proof | Objection addressed | CTA |
|---|---|---|---|---|

### Claim-Proof Matrix
| Claim | Evidence | Strength | Risk | Revision |
|---|---|---|---|---|

## 6. FAILURE MODES

Avoid vague claims, feature dumping, empty adjectives, generic headlines, proof-free urgency, hidden conditions and message mismatch between ad, landing page and offer.

## 7. OBAVEZNI OUTPUT

1. Audience and awareness.
2. Message hierarchy.
3. Value proposition.
4. Proof and objections.
5. Draft copy/structure.
6. Required matrices.
7. CTA.
8. Integrity check.

End with **Provera integriteta poruke** confirming every material claim is supportable and relevant to the audience.

Ovaj prompt podržava copywriting i ne garantuje conversion uplift.
