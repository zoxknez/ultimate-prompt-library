## How to contribute

- Open a **prompt suggestion** issue describing the prompt you would like to see or write. Check the [catalog](../../../catalog.json) and existing issues first to avoid duplicates.
- Prompt IDs for this category use the `UPL-CREATIVE-NNN` prefix and are assigned only after a proposal is accepted.
- New prompts should follow the [prompt format guide](../../../docs/prompt-format.md) and ship in English and Serbian before they are marked `stable`.

See [CONTRIBUTING.md](../../../CONTRIBUTING.md) for the full process.
