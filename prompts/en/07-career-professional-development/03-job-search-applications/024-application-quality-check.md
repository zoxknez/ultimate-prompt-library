# APPLICATION QUALITY CHECK

Main objective:

> Perform a practical, evidence-based workflow for Application Quality Check, using verified experience, clear signals and no fabricated claims.

## 1. CONTEXT

Define target role/company, actual experience, achievements, constraints, seniority, location/remote preference, application stage and desired outcome.

## 2. DOMAIN STANDARD

Treat job search as a funnel with limited attention. Prioritize roles using verified fit, role quality and application cost. Research current company/role information when available, but separate public facts from inference.

## 3. INTEGRITY CHECKS

- must-have criteria are separated from preferences
- application effort matches opportunity quality
- company claims are source-checked where material
- outreach is personalized but concise
- follow-up cadence is professional
- tracker measures stage conversion, not only volume

## 4. EVIDENCE CARD

```text

Action:
Scope:
Result:
Metric:
Context:
Relevance:

```

## 5. REQUIRED MATRICES

### Vacancy Triage Matrix
| Role | Must-have fit | Evidence | Gap | Quality signal | Effort | Priority |
|---|---|---|---|---|---|---|

### Funnel Matrix
| Stage | Count | Conversion | Main loss reason | Experiment |
|---|---:|---:|---|---|

## 6. FAILURE MODES

Avoid fabricated metrics, generic adjectives, keyword stuffing, vague outreach, rehearsed answers with no evidence, irrelevant portfolio material and activity metrics that do not improve conversion.

## 7. REQUIRED OUTPUT

1. Target and context.
2. Evidence inventory.
3. Fit/gap analysis.
4. Draft or workflow.
5. Quality risks.
6. Required matrices.
7. Next action.
8. Verification checklist.

End with **Application Integrity Check** confirming that every material claim is supported by real experience or explicitly marked as an assumption.

This supports career work and does not guarantee selection or an offer.
